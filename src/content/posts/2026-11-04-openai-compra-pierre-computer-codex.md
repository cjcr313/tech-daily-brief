OpenAI anunció hoy que **adquirirá Pierre Computer Company, Inc.**, la empresa detrás de **Code Storage** y una familia de herramientas open source para desarrolladores que ya viven dentro de Codex. Si alguna vez navegaste archivos o revisaste un cambio en la app de Codex, ya usaste el trabajo de Pierre sin saberlo: sus librerías **Trees y Diffs** son las que muestran el árbol de archivos y los diffs ahí.

## ¿Qué se lleva OpenAI en el deal?

- **Trees**: navegación rápida del árbol de archivos de un proyecto.
- **Diffs**: visualización de cambios con rendimiento brutal, incluyendo un *Edit mode* que permite corregir una línea justo donde el revisor ve el problema.
- **Highlights**: un syntax highlighter rapidísimo que se actualiza mientras el dev escribe o mientras un agente hace streaming de código.
- **Code Storage**: un servicio con API para que apps almacenen código y trackeen su historial usando Git.

La jugada no es solo talento. Axios, que tuvo el exclusivo, lo enmarca como un **golpe directo al territorio de GitHub**: OpenAI quiere que Codex sea el lugar donde devs y agentes construyen, entienden y revisan código de punta a punta — "desde la primera rama que crea un agente hasta el momento en que el código llega a producción", dice el anuncio.

## El contexto: Pando y el Git a escala de agentes

Esto no salió de la nada. A principios de semana OpenAI publicó cómo está **escalando Git internamente con Pando**, su backend de control de versiones hecho en casa para ingenieros y agentes: tiempos medianos de push reducidos en casi 80% y cerca de **un petabyte de datos Git diarios**. Con Pierre suman las piezas de UI y storage para armar una plataforma completa de desarrollo con agentes en el centro.

## Lo importante para el ecosistema

- Los proyectos open source de Pierre **siguen siendo open source**, y OpenAI dice que seguirá contribuyendo.
- Los clientes de Code Storage pueden seguir usándolo tras el cierre, mientras sus funciones se integran a Codex.
- El cierre está sujeto a aprobaciones regulatorias; hasta entonces, ambas empresas operan separadas.

Para los que trabajamos en plataformas de desarrollo, la señal es clara: la capa de code review y source control se está rediseñando **alrededor de agentes que trabajan en paralelo**, no de humanos en serie. Microsoft/GitHub tiene Copilot; OpenAI ahora tiene stack completo. La pelea por el repositorio del futuro recién está empezando.
